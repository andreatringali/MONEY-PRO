# Sito Aziendale — Fotovoltaico Utility Scale · EPC · Eolico

Galleria di **10 proposte grafiche** per il sito dell'azienda: installazione di
impianti fotovoltaici utility scale, servizio full EPC (Engineering, Procurement
& Construction) e impianti eolici.

## Come vedere le proposte

Apri `index.html` in un browser. È una pagina singola, autonoma, senza
dipendenze esterne.

Scorri verso il basso: ogni proposta occupa una schermata con il proprio sfondo
dinamico, profondità 3D e animazioni allo scroll — il contenuto centrale resta
"fermo" mentre gli elementi entrano ed escono ai lati. La barra laterale a
destra permette di saltare a una proposta specifica.

## Note

- Il marchio **HELIOS** e i dati (GWp, progetti, ecc.) nei mock sono
  **segnaposto**: vanno sostituiti con nome, logo e numeri reali dell'azienda.
- Design responsive, con supporto tema chiaro/scuro e `prefers-reduced-motion`.
- Una volta scelta la direzione, si costruisce il sito completo (home, pagine
  impianti / EPC / eolico, contatti).
